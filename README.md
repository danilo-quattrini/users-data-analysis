# Users Data Analysis
Laboratory project of data science where perform machine learning algorithms in order to compute and analyze users data. The task of this laboratory is to evaluate the
performance of the classification made from these algorithms and it is necessary to test and compare different settings of these
configuration. To validate the performance of the classifiers, you must use a process
of 10-fold Stratified Cross validation. The results obtained from each algorithm must be
analyzed to assess the impact of the main input parameters.
